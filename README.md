# CodeNova Internship — Task 1: Exploratory Data Analysis (EDA)

## 1. Overview

This project performs Exploratory Data Analysis (EDA) on the Palmer Penguins dataset using Python. The goal is to understand the dataset, identify data quality issues, clean the data, detect potential outliers, and visualize patterns in penguin measurements.

## 2. Project Objectives

- Understand the dataset structure and data types.
- Identify missing values and duplicate records.
- Handle missing values using suitable imputation methods.
- Detect potential outliers using the Interquartile Range (IQR) method.
- Create meaningful visualizations to identify patterns and relationships.
- Summarize important observations from the analysis.

## 3. Dataset

**Dataset name:** Palmer Penguins

**Source:** Seaborn sample datasets  
https://github.com/mwaskom/seaborn-data

The dataset contains penguin measurements and categorical information, including species, island, bill dimensions, flipper length, body mass, and sex.

The notebook downloads `penguins.csv` automatically if the file is not already available locally.

## 4. Project Files

- `eda_analysis.ipynb` — Jupyter notebook containing the analysis, code, and explanations.
- `requirements.txt` — Required Python libraries.
- `penguins.csv` — Original dataset.
- `penguins_cleaned.csv` — Cleaned dataset generated by the notebook.
- `visualizations/` — Exported charts and analysis outputs.
- `.gitignore` — Specifies files and folders Git should ignore.

## 5. Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 6. Data Cleaning and Analysis

The notebook performs the following operations:

1. Loads and inspects the dataset.
2. Checks the number of rows and columns, data types, descriptive statistics, and missing values.
3. Identifies and removes exact duplicate rows.
4. Fills missing numerical values using the median.
5. Fills missing categorical values using the mode.
6. Detects potential numerical outliers using the IQR method without automatically deleting them.
7. Creates summary statistics grouped by penguin species.

## 7. Visualizations

The project generates the following visualizations:

- Histograms to examine numerical data distributions.
- Boxplots to inspect distributions and potential outliers.
- A correlation heatmap to examine relationships between numerical variables.
- Pairwise scatter plots to explore relationships between measurements and species.
- Species-level summary statistics to compare measurements.

The notebook also exports visualization images to the `visualizations/` directory.

## 9. How to Run the Project

### Prerequisites

- Python 3.10 or newer.
- Visual Studio Code with the Python and Jupyter extensions.
- An internet connection for the initial dataset download, if needed.

### Installation

1. Extract the project ZIP file.
2. Open the `CodeNova_Task_1_EDA` folder in VS Code.
3. Open **Terminal → New Terminal**.
4. Install the required libraries:

   ```bash
   python -m pip install -r requirements.txt
   ```

5. Open `eda_analysis.ipynb`.
6. Select the appropriate Python kernel.
7. Click **Run All** to execute the notebook.
8. Review the outputs and generated visualization files.

## 10. Limitations

- Imputation can affect data distributions and summary statistics.
- Potential outliers may represent valid observations and are not automatically removed.
- Correlation does not establish causation.
- Findings apply to the dataset analyzed and may not represent every penguin population.

## 11. Conclusion

This project demonstrates a complete exploratory data analysis workflow, including dataset profiling, data cleaning, potential outlier detection, visualization, and interpretation. It provides a foundation for understanding the data before applying machine learning techniques.
